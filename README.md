# Tienda Deportiva App

Aplicación híbrida para tienda de ropa deportiva desarrollada con Ionic + Angular + Capacitor.

## Características

- ✅ Autenticación (login/registro)
- ✅ Servicios API (consumo de datos desde backend)
- ✅ Carrito de compras
- ✅ Almacenamiento local
- ✅ Compilación para Android e iOS

## Tecnologías

- **Frontend**: Ionic + Angular
- **Mobile**: Capacitor
- **Backend**: JSON Server (simulación API REST)
- **Base de datos local**: Ionic Storage

## Instalación

```bash
npm install
```

## Desarrollo

```bash
ionic serve
```

## Compilación

### Android
```bash
ionic capacitor build android
```

### iOS
```bash
ionic capacitor build ios
```
