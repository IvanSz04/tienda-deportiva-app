# Changelog

Todos los cambios notables de este proyecto serán documentados en este archivo.

## [1.0.0] - 2024-01-XX

### ✅ Agregado
- **Configuración inicial**: Setup de Ionic + Angular + Capacitor
- **Autenticación**: Sistema de login y registro con validaciones
- **Navegación**: Tabs con Home, Productos, Carrito y Perfil
- **Catálogo**: 6+ productos deportivos con búsqueda y filtros
- **Carrito**: Funcionalidad completa de e-commerce
- **Almacenamiento**: Persistencia local para carrito y usuario
- **UI/UX**: Diseño responsive con Loading Skeleton
- **Componentes**: ProductCard y LoadingSkeleton reutilizables
- **Servicios**: ProductService, CartService, AuthService, StorageService
- **Tema**: Colores deportivos (azul, naranja, verde)

### 🎨 Mejorado
- **Responsive Design**: Grid adaptativo para móvil/tablet
- **Animaciones**: Transiciones suaves y hover effects
- **Performance**: Lazy loading y componentes optimizados
- **UX**: Estados de carga y feedback visual

### 📱 Técnico
- **TypeScript**: Tipado estático completo
- **RxJS**: Programación reactiva
- **SCSS**: Estilos modulares y variables CSS
- **ESLint**: Configuración de linting
- **Capacitor**: Preparado para build nativo

## Commits Realizados

1. **Setup inicial**: Configuración de proyecto y dependencias
2. **Routing**: Sistema de navegación con lazy loading
3. **Auth**: Módulos de login y registro
4. **Services**: Servicios de productos y carrito
5. **Home**: Página principal con productos destacados
6. **Cart**: Carrito de compras completo
7. **Storage**: Almacenamiento local mejorado
8. **UI/UX**: Diseño responsive y componentes
9. **Final**: Integración y documentación
